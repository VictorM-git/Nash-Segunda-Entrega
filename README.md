# NASH

Banco de parciales, quices, apuntes y talleres de las carreras de la Universidad del Rosario,
organizado por carrera y materia y subido por estudiantes.

**Todo lo del proyecto del curso (enunciado, arquitectura AWS, entregas y cómo conectar la base de datos)
está en [PROYECTO-FINAL-CN.md](PROYECTO-FINAL-CN.md).**

## Verlo en el computador

```bash
cd frontend
python -m http.server 8765
```

Abre <http://localhost:8765>. Sin `frontend/js/config.js` lleno, corre en modo local: el banco empieza
vacío y lo que subas queda solo en ese navegador. Cuenta de prueba: `prueba@urosario.edu.co` /
`nash2026` (o `app.html?demo`).
